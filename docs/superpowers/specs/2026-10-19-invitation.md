# Abi's invitation platform

Authorized scope: Spanish mobile-first second birthday invitation at xitlaliabigail.com; October 24, 2026 16:00 America/Ciudad_Juarez. Weather notice changes 17:00 to 16:00. Calle Arquitectura 419; parking in front and additional space on Ingeniería beside park. Do not assert unverified neighborhood name or parking coordinates. Include clothes size 2, warm pajamas/winter clothes, Chimuelo/Teletubbies, lluvia de sobres, bring your own beer. Use supplied illustrations, forest colors and Viking village decoration.

Private random invitation per family, head-of-family greeting, unlimited family attendance (nonnegative integer adults/children, at least one when attending). Guests may revise RSVP. No phone/email exposed in public responses. No external sending providers.

Go HTTP API and Lambda share handlers. DynamoDB on-demand stores families and hashed device credentials; conditional revision writes protect concurrent changes. Static HTML/CSS/JS on private S3 via CloudFront, same-origin /api routed to API Gateway. Admin login uses a deployment-generated strong key exchanged for a 12-hour signed Secure HttpOnly cookie; browser does not persist that key. Rate-limited API Gateway; no public registration. Admin can issue/revoke device credentials. Android stores credential encrypted with Android Keystore. Device can read family list, claim/release work and report sending; cannot edit contact data, issue credentials or alter RSVP. Never put guest data or credentials in Git.

Sending status is separate from assignment and RSVP. Persistent attempt ID before SMS; unknown/crashed attempts require human reconciliation rather than automatic retry. Conditional claim prevents two devices working the same family. Manual SMS/WhatsApp completion is explicitly labeled. WhatsApp handoff never proves sending. Android maintains durable local outbox and syncs pending updates; starts no new send when backend begin cannot be confirmed. SMS interval 10 seconds, permission/SIM checks, one-segment text required in first version, pause on failure; user keeps app open for a short batch. No background service complexity. Sent callbacks survive activity recreation using manifest receiver. App restart converts unresolved in-flight SMS to uncertain.

Deployment wizard: Python standard library, Windows/Linux, prerequisites, AWS profile/SSO login, S3 state bootstrap encryption/versioning/public block, Pulumi passphrase, Cloudflare scoped token, preview then explicit deploy prompt. Pulumi TypeScript infrastructure. Admin secret not shown in logs. Import CSV name,phone,email with optional stable id; preview default, conditional create only, never overwrite response/status. API contract documented in both repos.

Tests: Go handler tests for auth, RSVP privacy/validation, concurrent ownership, idempotent attempts, device revocation. Browser smoke tests for invitation/admin. Android pure queue tests and build/lint where SDK available. No cloud deployment or real messages in this session.
